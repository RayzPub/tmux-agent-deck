# ⚡ 新手极速上手指南

欢迎来到 **CCNOW 多设备 AI 智能体控制中心**！
核心使用路径只需记住这一条链：**选设备（云电脑 / 主服务器 / 我的电脑）➔ 选工作区 ➔ 启动智能体会话 ➔ 任务看板全局掌控**。

---

### 1️⃣ 第一步：选择或接入算力设备 (Device)

在左侧侧边栏顶部的 **「当前设备」** 下拉框中，可随时在不同算力节点之间切换（工作区、会话列表、文件树与任务看板会自动同步）：

- ☁️ **云电脑 (`Docker Sandbox`)**：每位受邀用户专属的云端隔离容器，支持按需秒级唤醒、闲置自动休眠（文件持久保留），并内置安全代理模型，开箱即用。
- 🖥️ **主服务器 (`Host Admin`)**：管理员专属宿主机常驻服务，独立于网页服务进程运行，升级重启不掉线。
- 💻 **我的电脑 (`Mac / Windows / Linux`)**：想直接操控自己电脑上的代码库与本地模型？打开左下角 **「系统设置」➔「设备管理」**，复制一次性配对命令在本地终端运行即可反连接入，**无需公网 IP，也不强制依赖 Tmux**（原生流 OAR 会话开箱即用）。

👉 <a href="#device-manager" class="doc-action-card-btn">💻 打开设备管理 / 唤醒云电脑</a>

---

### 2️⃣ 第二步：准备代码工作区 (Workspace)

- **直接使用默认工作区（推荐新手）**：系统已为您自动初始化个人默认工作区，零配置直接开工。
- **绑定现有项目目录（进阶）**：在左侧 **「当前工作区」** 下拉菜单中可切换已有工作区，或新建工作区并点击文件夹图标直接浏览服务器/本机目录绑定。

---

### 3️⃣ 第三步：启动智能体会话 (Session)

#### 3.1 免起名烦恼：自动编号 + AI 自动摘要标题
新建会话时，**「会话名称」可直接留空**！系统会自动分配全局唯一自增 ID，并在您发出第一条消息后，自动用 AI 摘要成清晰易读的任务标题（随时可在侧边栏或看板内重命名）。

#### 3.2 两种会话运行模式怎么选？
- 🔀 **终端双模 (Tmux，默认推荐)**：基于 Tmux 终端驱动，可视化对话界面与完整字符终端实时同步、随时一键互切；若选择 **Shell (标准 Bash)** 则自动以纯终端命令行启动。
- 💬 **原生流 (OAR)**：基于 Open Agent Runtime 原生事件流直连智能体，轻量纯净、免终端按键干扰，支持 `/compact` 上下文压缩且**不依赖 Tmux**。

#### 3.3 五大内置智能体环境
- 🌌 **Antigravity (`agy`)**：擅长复杂架构规划、多步骤自主执行与全自动流水线。
- 🤖 **Claude Code (`claude`)**：Anthropic 官方终端智能体，擅长代码库全局理解与精细重构。
- ⚡ **Codex CLI (`codex`)**：OpenAI 终端编程助手，擅长快速代码生成、审查与调试。
- ✨ **Kimi Code (`kimi`)**：Moonshot 终端智能体，原生中文理解优秀。
- 🐚 **Shell (`Bash`)**：标准命令行环境，适合构建脚本与运维排查。

*(💡 提示：在创建面板中可按会话选择内置 LLM 网关模型；管理员也可在「系统管理」开启 Claude OAuth 官方直连模式。)*

👉 <a href="#new-session" class="doc-action-card-btn">⚡ 立即创建智能体会话</a>

#### 3.4 🎯 新手推荐第一战：1 分钟生成可分享的网页小应用
创建会话后切入 **「对话」** 模式，空白页已贴心内置灵感小气泡，点一下即可开跑：
- 📊 **周五周报排版器**：输入零散流水账，一键排版为工整汇报卡片并支持复制。
- 🎡 **中午吃什么转盘**：纯 Canvas 丝滑大转盘，支持自定义菜品与抽中撒花。
- ⏱️ **专注番茄钟看板**：极简科技感表盘，带 25/5 分钟专注打卡与久坐提醒。
- 💰 **薪资个税测算器**：输入税前月薪，动态可视化呈现五险一金扣除与税后收入。
- 📋 **四象限任务便签**：基于“重要-紧急”法则的便签看板，支持拖拽与本地暂存。

*(✨ 产物玩法：AI 回复中提到的**文件路径可直接点击**打开并内嵌预览网页；点击预览按钮右侧下拉菜单，还能一键生成 **1–72 小时限时免密分享链接**发给好友体验！)*

---

### 4️⃣ 第四步：进阶效率神器（强烈推荐）

- 📋 **任务看板总览 (`Kanban`)**：点击左侧 **「任务看板总览」**，跨工作区按 **需确认 / 执行中 / 待命 / 待办** 四列（或按工作区网格）全局盯盘。支持直接在卡片上**快捷回复指令、重命名标题**，还能随手记待办并一键拉起会话。
  👉 <a href="#task-board" class="doc-action-card-btn">📋 打开任务看板总览</a>
- ⌨️ **智能体感知 `/` 快捷指令**：在对话输入框或终端底部快捷栏点击 **`/`**，自动弹出适配当前智能体的专属命令菜单（如 `/plan`、`/goal`、`/compact`、`/clear`、`/new`、`/review`、`/diff`、`/model` 等），无需死记硬背。
- 📈 **Mermaid 图表 & 文件路径直达**：AI 输出的架构图、时序图、流程图自动渲染为高清 SVG（支持点击放大灯箱与源码切换）；回复中的代码路径（甚至 `file.js:42` 行号）点击即在 Monaco 编辑器精准定位。
- 🔍 **文件浏览器与 Git Diff**：切换左侧 **「文件浏览器」** 支持拖拽上传图片/代码/文档、在线编辑保存以及一键筛查 Git 修改差异。

---

### 5️⃣ 第五步：多端协同与个性化

- 🔄 **后台 7×24 持久化**：关掉浏览器、手机锁屏甚至切换网络，AI 仍在后台持续工作，重连瞬间恢复现场。
- 📱 **手机与折叠屏 PWA**：点击左下角 **「系统设置」➔「手机扫码连接」** 获取临时免密二维码，添加到主屏幕即可全屏沉浸运行，自带虚拟辅助键盘与语音输入。
- 🔔 **离线消息推送**：在 **「系统设置」** 中开启「消息推送」，AI 完成长任务或等待审批时自动推送系统通知。
- 🎨 **深浅双主题切换**：在 **「系统设置」** 一键切换 **赛博朋克（深色）** 与 **浅色极简** 双主题，护眼舒适。
