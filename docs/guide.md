# ⚡ 新手极速上手指南

只需 3 步，即可在 CCNOW 启动并掌控您的第一个 AI 编程智能体：

---

### 1️⃣ 第一步：工作区准备 (Workspace)
- **确认使用默认工作区（推荐）**：系统已为您自动分配并初始化了专属的个人工作区，新手**直接确认使用当前默认工作区即可**，无需任何繁琐配置，开箱即用！
- **进阶：在左侧新建工作区**：若需要绑定服务器上现有的特定项目代码目录，随时可以在左侧侧边栏的 **「当前工作区」** 旁点击 **`+`** 按钮，输入服务端绝对路径创建并切换为专属工作区。

---

### 2️⃣ 第二步：启动智能体会话 (Session)

#### 2.1 选择适合当前任务的 AI 智能体
- 🤖 **Claude Code**：Anthropic 官方终端智能体，擅长代码库全局理解、复杂重构与全栈开发。
- 🌌 **Antigravity (agy)**：Google DeepMind 极客智能体，擅长多任务自主规划与全自动流水线。
- ⚡ **Codex Agent / Linux Shell**：轻量级代码编写、脚本执行、编译调试与系统运维。

#### 2.2 一键创建与启动
无需离开当前指南，点击下方快捷入口直接弹出创建面板：

👉 <a href="#new-session" class="doc-action-card-btn">⚡ 立即创建智能体会话</a>

#### 2.3 🎯 新手推荐第一战：单页网页小应用
智能体非常擅长在 1 分钟内为您编写开箱即用、零环境依赖的单文件 HTML 网页小工具。
创建会话后切入右上角 **「对话」** 模式，空白页已贴心提供灵感小气泡，点击即可快速填入并确认发送：
- 📊 **周五周报排版器**：输入零散流水账，一键排版为工整汇报卡片并支持复制。
- 🎡 **中午吃什么转盘**：纯 Canvas 丝滑大转盘，支持自定义菜品与抽中撒花。
- ⏱️ **专注番茄钟看板**：极简暗黑科技感表盘，带 25/5 分钟专注打卡与久坐提醒。
- 💰 **薪资个税测算器**：输入税前月薪，动态可视化呈现五险一金扣除与税后收入。
- 📋 **四象限任务便签**：基于“重要-紧急”法则的便签看板，支持拖拽与浏览器暂存。

*(💡 产物提示：生成后的 HTML 文件会实时出现在左侧文件树中，点击即可直接在编辑器与网页中查看！)*

---

### 3️⃣ 第三步：核心体验与多端协同
- 🔄 **云端持久化**：所有智能体在服务端的 Tmux 中运行，**关闭网页或手机断网任务仍持续进行**，随时重连恢复现场。
- 📱 **手机扫码即连**：右上角「系统」菜单可打开二维码，手机访问自适应沉浸式对话模式与虚拟辅助键盘。
- 🔔 **离线消息推送**：在右上角开启「消息推送」，智能体耗时任务完成或需权限确认时自动通知。
