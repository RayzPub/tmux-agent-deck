// ARCHITECTURE

统一控制面 · 多设备算力模型

一套 Web 控制面通过 /device-tunnel 与模块化 ccnow-agent 统一纳管所有算力，左上角一键切换设备即可无缝切换工作区、会话、文件树与任务看板。

Control Plane 控制面 → User 租户 → Device 算力设备 → Workspace 工作区 → Session 智能体会话

云电脑 · 托管沙箱

docker-sandbox

为每位受邀用户分配独立硬化 Docker 容器，开箱即得云端开发环境，彻底消除多租户越权与资源抢占。

  • 非 root 运行、--cap-drop=ALL 与 CPU / 内存 / PIDs 硬限额
  • 按需秒级唤醒、闲置自动休眠释放内存，挂载卷持久保留代码
  • 通过作用域虚拟 Key 访问控制面 LLM 网关，真实 API Key 零暴露

我的电脑 · 边缘接入

external

把家里的 Mac、办公室的 Linux 或 Windows 笔记本直接接入云端面板，本地代码库与工具链零迁移。

  • 一行配对命令反连 443 端口，天然穿透 NAT 与防火墙，零端口暴露
  • 按需自动补全可选依赖，没装 Tmux 也能直接运行原生流 (OAR) 会话
  • 保留本机模型配置与 OAuth 登录态（BYOK），不消耗云主机带宽

主服务器 · 宿主机常驻

host-admin

将控制面所在云主机注册为管理员专属常驻节点，作为个人主力研发与系统运维的高速算力底座。

  • 独立 systemd 进程树隔离，重启控制面服务会话永不掉线
  • 本机回环直连 LLM 网关与本地文件，零延迟、零公网流量损耗
  • 支持远程自动热更新与防误删保护，7×24 稳定在线
// FEATURES

核心功能特性

从对话引擎、全局任务看板到代码预览分享，为 AI 原生研发工作流量身打磨每一个细节。

双引擎会话 & 五大智能体环境

精简为 终端双模 (Tmux)（对话与终端随时互切，选 Bash 自动以纯终端启动）与 原生流 (OAR)（免 Tmux 直连流式对话）两种模式；内置 Antigravity、Claude Code、Codex、Kimi Code 与 Bash 一键启动，留空会话名自动分配唯一自增 ID 并 AI 摘要任务标题。

任务看板总览 (Session-as-Task)

跨工作区全局盯盘视图，按「需确认 · 执行中 · 待命 · 待办」四列看板或工作区网格实时聚合全部会话状态。支持卡片内直接回复指令、重命名标题、搜索过滤，以及待办任务一键拉起会话。

富媒体对话 · Mermaid & 路径直达

AI 输出的 Mermaid 流程图/架构图 自动渲染并支持双主题适配、源码切换与缩放灯箱；回复中提到的 文件路径（含行号） 点击即在编辑器打开定位；更有智能体感知 / 快捷指令面板。

在线编辑、Git Diff 与限时分享

集成 Monaco 代码编辑器、红绿 Git 变更审查与文件拖拽上传；内置 Markdown、图片与 HTML 实时预览，并可为生成的网页产物一键生成 1–72 小时限时免密分享链接。

LLM 统一网关 & SQLite 持久化

后台内置多厂商 LLM Gateway 与可视化配置器，支持按会话选模型及 Claude OAuth 官方直连；控制面数据全面基于 node:sqlite WAL 模式持久化，搭配管理员邀请码注册与 JWT 鉴权。

深浅双主题 · 手机与折叠屏 PWA

支持赛博深色与浅色极简双主题及自定义桌面图标；深度适配手机与折叠屏视口，内置虚拟辅助键、语音输入与 Web Push 离线推送，息屏也能及时收到 AI 完成或审批提醒。

// FAQ

常见问题

关于多设备架构、会话模式、安全隔离与日常使用的高频解答。

不会。所有 AI 会话都由底层设备上的 Tmux 或 OAR 运行时持久托管，网页只是轻量的控制端。宿主机 Agent 与控制面均运行在相互独立的 systemd 单元中，不仅关页、断网不中断，即使升级重启 Web 服务，正在执行的智能体会话也会保持运行并在数秒内自动重连。

终端双模 (Tmux，默认推荐)基于 Tmux 驱动，兼顾可视化聊天气泡与完整 ANSI 终端，随时一键互切；若选择标准 Bash (Shell)，则自动以纯终端启动。原生流 (OAR) 由 Open Agent Runtime 驱动原生结构化事件流与工具调用闭环，免终端按键干扰、支持 /compact 压缩上下文，且无需安装 Tmux（非常适合 Windows 或轻量环境）。

不需要公网 IP，也无需配置端口转发。登录网页后在「设备管理」点击复制一次性配对命令，在你的 Mac / Linux / Windows 终端执行即可。ccnow-agent 会主动向控制面发起出站加密 WebSocket 连接，自动适配 NAT、公司防火墙或手机热点网络。

安全。多用户模式下，每位普通用户由独立的硬化 Docker 沙箱（非 root、丢弃全部内核特权、硬性 CPU/内存/进程数配额）提供内核级隔离，彼此工作区完全不可见。所有真实上游 API Key 仅存储在云端控制面，沙箱只持有作用域虚拟 Key，无法读取或窃取明文上游密钥；注册采用管理员一次性邀请码机制。

内置 Antigravity (agy)、Claude Code、Codex CLI、Kimi Code 以及标准 Bash Shell 五大环境。支持通过内置 LLM Gateway 统一配置多厂商模型并在新建会话时按需切换，也支持开启 Claude OAuth 官方直连模式或使用本机自有模型订阅（BYOK）。

非常顺手。界面针对手机竖屏与折叠屏大屏做了专项视口和安全区适配，支持 PWA「添加到主屏幕」全屏运行。内置手机端快捷辅助键盘（ESC、TAB、Shift+Tab、Ctrl+C、/ 智能体指令、方向键）和语音输入，配合 Web Push 离线推送，出门在外也能随时审批与接力研发。
